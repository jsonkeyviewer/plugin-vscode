# Changelog

All notable changes to JSON YAML XML Key Viewer are documented in this file.

## 1.0.0 — 2026-10-05

- Display full dot-notation paths for JSON, JSONC, YAML, and XML keys.
- Show optional value types in hover tooltips.
- Support array indices, repeated XML siblings, self-closing XML elements, and keys
  containing literal dots.
- Display optional inline key paths with VS Code Inlay Hints.
- Detect dense or minified lines and provide a clickable document-format action.
- Allow each supported language to be enabled or disabled from VS Code settings.
